# Прототип нового сайта ВЕНТПРОМ

## Как открыть

Двойной клик по **`ЗАПУСК.cmd`**. Откроется браузер на `http://localhost:8080/`.
Закрыть чёрное окно — остановить сервер.

Почему не просто двойной клик по `index.html`: страницы собраны на ES-модулях,
а браузер не грузит модули по `file://` — блокирует политика источников.
Сервер написан на PowerShell поверх .NET-сокетов, ставить ничего не нужно.

## Что здесь настоящее, а что демонстрационное

**Настоящее** — снято с боевого сайта и не изменено: 13 разделов и счётчики
позиций, 60+ серий с опубликованными диапазонами Q, P, N и оборотов,
исполнения (Ж2, К1, К1Ж2, В, ВЖ2, ВК1, ВК3), нормативы ТУ и ГОСТ, реквизиты,
объекты, 19 регионов.

**Демонстрационное** — помечено на экране плашкой ДЕМО и сноской: конкретные
типоразмеры внутри серий, аэродинамические кривые, КПД, массы, уровни шума,
сроки, статусы заказов. Всё это построено из опубликованных диапазонов по
законам пропорциональности и **подлежит замене выгрузкой завода**.

**Чего нет намеренно:** цен, номеров сертификатов, отзывов, года основания,
гарантийных сроков. Ничего из этого не выдумано.

## Что нужно от завода, чтобы прототип стал сайтом

1. Выгрузка номенклатуры: серии, типоразмеры, аэродинамические характеристики.
2. Методика подбора — как менеджер подбирает сегодня.
3. Права на графики характеристик (сейчас на боевом сайте они грузятся
   с посторонних доменов).
4. Настоящие таблицы для серий, где данные продублированы с ВР 80-75.
5. Решение по ценам: публиковать или оставить «по запросу».
6. Логотип в векторе и фирменные цвета.
7. Номера, сроки и орган сертификации.
8. Судьба разделов вне рамки «только вентиляция»: крепёж, воздуховоды,
   фильтры, тепловое оборудование.

Полный список — в `..\..\08_Разведка_боевого_сайта.md`, раздел 8.

## Ограничения прототипа

- Бэкенда нет. Вход, объекты, статусы КП живут в `localStorage` браузера.
  Это соответствует архитектуре: состояние пользователя существует до
  регистрации, а регистрация только поднимает его в облако.
- Ссылка «поделиться объектом» локальная — сервера для токенов нет.
- 3D-модель вентилятора не подставлена: `.glb` от завода не получен.
  Заготовка сцены — в `..\fan3d-scroll.html`.
